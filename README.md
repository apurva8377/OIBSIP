# Oasis Infobyte Java Development Internship - Task 3

## Project Name: ATM Interface
**Author:** Apurva Vilas Shinde  
**Description:** A console-based Java application simulating an Automated Teller Machine (ATM) with secure user authentication, account balance management, cash withdrawals, deposits, and account-to-account fund transfers using Object-Oriented Programming (OOP) principles.

### Features
* **Secure Authentication:** User ID and 4-digit PIN verification with a 3-attempt lockout security limit.
* **Interactive Main Menu:** Options for checking balance, viewing session transaction history, withdrawing, depositing, transferring funds, and quitting.
* **Fund Validation:** Prevents overdrafts and illegal transactions with real-time balance checks.
* **Multi-Class Architecture:** Built using 5 distinct Java classes (`Main`, `ATM`, `Bank`, `Account`, `Transaction`).
